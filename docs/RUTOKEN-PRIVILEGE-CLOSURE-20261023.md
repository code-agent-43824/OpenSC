# Заключительная аппаратная проба полномочий, 2026-10-23

Источник — переданный владельцем `rutoken-privilege-closure-results-20261023.zip`,
SHA-256 `cfc33647bf04374a0ce08de031b9c0035fa110fce990ee94635ad50494e221a3`.
Сырые файлы в репозиторий не добавлены: приложенный `SUMMARY.txt` содержит
действующие PIN. Для выводов ниже использован `report.json` реального токена,
а не интерпретация из `SUMMARY.txt`.

Реальный Рутокен ЭЦП: `case=closure`, `status=complete`, 85 шагов. Модель
Rutoken ECP, аппаратная версия 67.4, прошивка 34.2, библиотека PKCS #11
2.21. SHA-256 модуля
`c39c9c570e222b5ab30a83b4ecc19610e4cad1aea0b9a6ccb388d5e33f75c531`
совпадает с предыдущим прогоном. SHA-256 CLI
`292d4e4e5063014b616407775fd87680befbaef0eb2e6f921915fda4e1c30b43`
совпадает с Linux x64 `0.27.1-portable.12` из опубликованного комплекта.
Приложенный `helper-used` совпадает с `report.helper_sha256`
`8240b3e8816c344ffa4a0cdd586c1bd3dc7453854d570c937ffc0a5164f21594`:
это тот же штатный helper с исправленным ABI, что в [повторной пробе](RUTOKEN-PRIVILEGE-FOLLOWUP-20261021.md).

Полный перебор всех ролей и типов сессий для каждой функции не проводился.
В частности, SO/RO останавливается на `C_Login`, а не на расширенной
функции. Нет наблюдения, указывающего на новый дефект CLI в проверенных
сочетаниях.

В том же архиве есть **отдельная** проба SoftHSM fork
`FAKE_RUTOKEN_ECP` (другой SHA-256 модуля). В ней mode 4 возвращает
`CKR_FUNCTION_NOT_SUPPORTED` (`0x54`), а имя в 256 байт отвергается с
`CKR_ARGUMENTS_BAD` (`0x7`) и через CLI, и прямым helper. Поэтому полный
`closure` корректно остановился до форматирования. Раздельные пробы
`license`, `name` и `repair` там завершились, но не доказывают ни mode 4,
ни предел имени физического Рутокена. Это различие поведения модулей,
а не ошибка `pkcs11-tool`.

Тестовая заглушка OpenSC раньше имела предел имени 255 байт из старого
наблюдения. Её проверяемый предел поднят до 4096 байт, с тестом полного
обратного чтения. Это **не** утверждение, что физический предел равен 4096:
он остаётся неизвестным. Новая аппаратная проба для него не нужна, пока
не появится конкретное требование на более длинное имя. Для моделей,
отличных от проверенной, результаты полномочий и пределов не обобщаются.
